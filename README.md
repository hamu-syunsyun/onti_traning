# 音程練習

歌の音程練習用 Web アプリ。お手本の3音を聞き、同じ音を歌う。ビルド不要で、`index.html` 1枚で動く。

## 現在の状態: 第1段階（音が鳴って進む）

- パターンA（移動型）/ パターンB（基準音型）の生成と進行
- Web Audio API による音源（triangle ベース＋偶数倍音、ADSR 0.01 / 0.1 / 0.7 / 0.3）
- お手本 → 1拍 → 「歌って」→ 結果 の進行。タップ進行（既定）と自動進行
- 経過時間の表示。5分を過ぎたら通知し、自動進行も止める
- 設定は localStorage に保存

第2段階（マイク判定）、第3段階（記録とグラフ）は未実装。

## 動かし方

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

スマホで試すときは HTTPS で配信する（GitHub Pages など）。第2段階のマイク入力は HTTPS か localhost でないと動かない。
iOS Safari は「共有 → ホーム画面に追加」でアプリとして使える。
