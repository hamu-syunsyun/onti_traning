# 音程練習

歌の音程練習用 Web アプリ。お手本の3音を聞き、同じ音を歌う。ビルド不要で、`index.html` 1枚で動く。

## 現在の状態: 第2段階（マイク判定）まで

- パターンA（移動型）/ パターンB（基準音型）の生成と進行
- ピアノ風の合成音（倍音ごとに減衰の速さを変え、ハンマーの打撃音を足したもの。音源ファイルは使わない）
- お手本 → 1拍 → 「歌って」→ 結果 の進行。1音の長さの既定は 0.5 秒。タップ進行（既定）と自動進行
- マイクでピッチ検出（McLeod Pitch Method、70〜1100Hz）。自分の声を線で重ね、判定後はズレで色分けする
- 各音の平均ズレ（中央60%）、出だしのズレ（最初の0.5秒、短い音は前半）、揺れ（標準偏差）をセントで表示
- 3音とも ±20 セント以内なら「PERFECT!」と虹色の演出、全部 ±50 以内なら「GOOD」
- 経過時間の表示。5分を過ぎたら通知し、自動進行も止める
- 設定は localStorage に保存

第3段階（記録と推移グラフ）は未実装。

## 動かし方

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

スマホで試すときは HTTPS で配信する（GitHub Pages など）。マイク入力は HTTPS か localhost でないと動かない。イヤホン使用が前提。
iOS Safari は「共有 → ホーム画面に追加」でアプリとして使える。
